- **The Bear House**: Visual Merchandising across 3 EBOs & 2 SIS stores; Hyderabad store pre-openings; EOSS sales turnaround.
- **Philocaly Menswear**: Store Manager directing 1,500+ SKUs, 10+ monthly replenishment cycles, and visual conversion.
- **Vijay Karnataka (Times of India Group)**: Conceptualized 4-page luxury edition and led B2B ad sales.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS with custom luxury editorial theme
- **Icons**: Lucide React
- **Hosting**: Vercel / Static Web
